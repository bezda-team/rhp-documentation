- **Hover is CSS the slat owns.** `.slat:hover .knots > span { opacity: 1 }`: no state, no handler.
- **The fade is inside the Label.** A transition set on a block would replace rhp's own, and the Label would jump to new values instead of moving with its bar.
- **A needle turned by data.** The compass in the start gutter is an element of the slat's own, not a block; its `rotate` comes from the row's quarter.

- **Art inside a Bar.** The fruit is an `<img>` inside the Bar, which crops it; the image fills the bar's length up to 300px.
- **v1's scale is a `Scale`.** One slat per tick from `every(5, { ends: true })`, a mark and its number. The scale ends at the largest value, so it refits as the data changes.
- **Drag Fruit A** to watch the scale refit and the slats re-rank; **Rank** and **Desaturate** are v1's buttons.

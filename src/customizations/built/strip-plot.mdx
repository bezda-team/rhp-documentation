Every patient is a Dot, and all the Dots of one group share a band.
The group's slat holds an `overlap` Plot, so its slats sit in the same space rather than stacking, and each one draws a single `Dot` at `d.at`.
`across` places a Dot across the band, from 0 to 1, and here it comes from the Dot's own index (`0.15 + ((s.index * 0.618) % 1) * 0.7`) rather than from a random number, so a patient keeps its place when the data changes.
A `Tick` at the mean and a start `Label` finish the group.

The gallery version adds:

- **Capsules instead of dots**, which is only CSS on the `Dot`: a border radius and a tilt.
- **A readout that never moves the chart.**
  Each Dot carries `data-arm` and `data-patient`, and the line above the chart is kept to one line, so pointing at a capsule changes the text without the chart jumping.

## How it's built

- **As many slats as the value needs.** An overlap Plot with `slats={Math.ceil(d.books / 5)}`, each spine from `index × 5` to the next five or the total.
- **A shelf that looks lived in.** Each spine's height and shade are fixed functions of its index, so they never change between renders.
- **Hover a book** to pull it half out: the book is an element inside its Bar, free to move and cast a shadow.

## How it's built

- **A stem and a tip.** A 4px Bar from 0 to the sample and a glowing Dot at its end, both fading with time through a CSS variable on each slat.
- **A one-tick `Scale`** draws the resting line.
- **Click the wave** to strike again: each sample's transition starts 8 ms after the one before, so the new ring runs down the wave (in the CSS version).

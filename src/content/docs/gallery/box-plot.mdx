## How it's built

- **Five numbers, four blocks.** `d.box` is `[low, box start, box end, high]`: two 6px Bars for the whiskers, Ticks for the caps, and a Bar for the box.
- **A photo in the box.** The box Bar holds an `<img>`, cropped to the box and zoomed in; hover a row and it zooms out. The cloud's name is the Label in the start gutter.
- **The slider** moves stratocumulus' box end, pushing its high whisker along, so you can watch the scale and the ranking follow.

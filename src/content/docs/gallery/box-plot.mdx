## How it's built

- **Five numbers, four blocks.** `d.box` is `[low, box start, box end, high]`: two 6px Bars for the whiskers, Ticks for the caps, and a Bar for the box with the cloud's name inside.
- **A photo in the gutter.** The start gutter's Label holds a circle with the photo, zoomed in; hover a row and it zooms out.
- **The slider** moves stratocumulus' box end, pushing its high whisker along, so you can watch the scale and the ranking follow.

A slat can hold a Plot of its own.
That inner Plot draws inside the slat, on the same scale, and its own slats follow the same rules as any other.
This one idea gives you stacked bars, grouped bars, heatmaps and more.

## Stacked bars

Each day's slat holds a Plot with `overlap`: its slats share the day's band instead of stacking, so its Bars line up end to end.
`stackUp` works out where each piece starts and ends.

## Grouped bars

Without `overlap`, the inner Plot splits the slat's band, one thin slat per item: three bars per team.

<Demo name="nesting-grouped" height={230} />

## Across the slat

`orientation="across"` turns the inner Plot the other way: its slats run along the scale instead of stacking.
That's how the [heatmap](/guides/blocks/#cell) puts one cell per hour in each day's slat.

## Tips

- An inner Plot gets its data from `d`: pass it `d.hours`, `d.medals` and so on.
- Work out derived data once per slat with `createMemo`, as the stacked example does with `stackUp`.
- `thick` on an inner Plot makes it use part of the slat's thickness: `thick={0.5}` is half.

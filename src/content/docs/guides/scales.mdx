## The scale

`scale` on the Chart sets the range of values it shows, as `[min, max]`.
Every block in every Plot of the chart uses it.

```jsx
<Chart scale={[0, 100]}>…</Chart>
<Chart scale={[-40, 40]}>…</Chart>      // negative values run the other way
<Chart scale={[0, Math.max(...values())]}>…</Chart> // a scale that follows the data
```

When the scale changes, everything on it moves together.
A Bar that runs past the scale is cut at its end; dots and labels are drawn where their values are.

## The axis

The Chart draws an axis on its own: grid lines with numbers.

- `ticks` picks the lines: a list (`[0, 25, 50, 75, 100]`), a rough count (`5`), or `false` for none.
- `format` turns a value into its text: `(v) => v + "%"`.

## Drawing the scale yourself

For a scale that looks different (dashed lines, numbers in a pill, bands between ticks), put a `Scale` in the Chart.
A Scale is a Plot of ticks: its row is drawn once per tick, and gets `d.at`, the tick's value.

<Demo name="scale-custom" height={220} />

A Scale row also gets:

- `d.next`, the next tick's value, to fill the space between two ticks,
- `d.first` and `d.last`, true at the two ends,
- `d.toEnd`, how far the tick is from the end of the scale in pixels, measured in the browser.

To leave out a number that would crowd the end of the scale, CSS is enough, and works the same when the chart is drawn on a server.
A Label's room from its value to the end is `calc((1 - var(--rhp-p)) * 100%)` in its `max-width` (in a vertical chart, `max-height`), so this gives a number with less than 30px no size at all:

```css
.num { max-width: calc(((1 - var(--rhp-p)) * 100% - 30px) * 1000); overflow: hidden; }
```

`every(10)` gives a tick at each multiple of 10.
`every(10, { ends: true })` adds the scale's two ends as ticks.

A Chart with a Scale in it draws no axis of its own.

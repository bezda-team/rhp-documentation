## The scale

`scale` on the Chart sets the range of values it shows, as `[min, max]`.
Every block in every Plot of the chart uses it.

```jsx
<Chart scale={[0, 100]}>…</Chart>
<Chart scale={[-40, 40]}>…</Chart>      // negative values run the other way
<Chart scale={[0, Math.max(...values())]}>…</Chart> // a scale that follows the data
```

When the scale changes, everything on it moves together.
A Bar that runs past the end of the scale is cut off there.
A Dot or a Label keeps the place its value gives it, even when that is outside the chart.

## The axis

The Chart draws an axis on its own: grid lines with numbers.

- `ticks` picks the lines: a list (`[0, 25, 50, 75, 100]`), a rough count (`5`), or `false` for none.
- `format` turns a value into its text: `(v) => v + "%"`.

## Drawing the scale yourself

For a scale that looks different (dashed lines, numbers in a pill, bands between ticks), put a `Scale` in the Chart.
A Scale is a Plot of ticks: its slat is drawn once per tick, and gets `d.at`, the tick's value.

<Demo name="scale-custom" height={220} />

A Scale slat also gets:

- `d.next`, the next tick's value, to fill the space between two ticks,
- `d.first` and `d.last`, true at the two ends,
- `d.toEnd`, how far the tick is from the end of the scale in pixels, measured in the browser.

A number near the end of the scale can collide with the last one.
CSS alone can hide it, and the same rule works when the chart is drawn on a server.
rhp gives every Label the room it has left, from its own value to the end of the scale, as `calc((1 - var(--rhp-p)) * 100%)`.
Put that in `max-width` (`max-height` in a vertical chart) and a number with less than 30px of room is given no size at all:

```css
.num { max-width: calc(((1 - var(--rhp-p)) * 100% - 30px) * 1000); overflow: hidden; }
```

`every(10)` gives a tick at each multiple of 10.
`every(10, { ends: true })` adds the scale's two ends as ticks.

A Chart with a Scale in it draws no axis of its own.

## A second axis

`cross` on the Chart adds a second scale, `[min, max]`, that runs across the slats: the y of a scatter plot or a line chart.
In a horizontal chart it runs from bottom to top, and in a vertical chart from left to right.

An `overlap` Plot's slats all share the whole plot, so a Dot or a Label with `cross` sits at its `at` on the scale and at its `cross` on the second axis: a scatter plot.

<Demo name="scale-cross" height={270} />

A [Line](/guides/blocks/#line) puts its points' y on the second axis: a line chart.
`fill` fills under the line, down to `base` (0 by default).

<Demo name="scale-cross-line" height={250} />

`crossTicks` and `crossFormat` set the second axis, like `ticks` and `format` for the first.
A horizontal chart with a second axis is 240px tall unless `height` says otherwise.

`cross` is optional.
A chart without it draws no second axis, and the CSS for one only reaches the page once some chart on it asks for a second axis.

title: Other frameworks
description: Use rhp inside a Vue, Svelte or Angular app by drawing it into an element.
---

rhp is built on Solid, but a chart is just elements on the page, so it can live inside an app built with anything else.
The idea is the same everywhere:

1. Give rhp an empty element to draw into.
2. Keep the chart's data in a Solid signal, and set it when your app's data changes.
3. Clean up when the component goes away.

Your app's templates belong to your framework, so the slats are written with Solid's `html` template, as in a [plain HTML page](/start/install/#in-a-plain-html-page).
`@bezda/rhp/standalone` has rhp, Solid and `html` in one import.
React is different: it has [an rhp of its own](/guides/react/).

## React

React has an rhp of its own, written with React: `@bezda/rhp-react`.
Its charts are React components, with React's state, and the server draws them too (Next.js included).
See [React](/guides/react/).

## Vue

```sh
npm install @bezda/rhp
```

```vue
<script setup>
import { onMounted, onBeforeUnmount, ref, watch } from "vue";
import { Chart, Plot, Bar, html, render, createSignal } from "@bezda/rhp/standalone";

const props = defineProps(["fruit", "sold"]);
const box = ref(null);
const [data, setData] = createSignal({ fruit: props.fruit, sold: props.sold });
let dispose;

onMounted(() => {
  const Fruit = (d) => html`<div><${Bar} to=${() => d.sold} /></div>`;
  dispose = render(() => html`
    <${Chart} scale=${[0, 30]}>
      <${Plot} fruit=${() => data().fruit} sold=${() => data().sold}>${Fruit}<//>
    <//>`, box.value);
});
watch(() => [props.fruit, props.sold], ([fruit, sold]) => setData({ fruit, sold }));
onBeforeUnmount(() => dispose?.());
</script>

<template><div ref="box" /></template>
```

## Svelte, Angular and others

The same three steps apply: draw with `render` into an element once it's on the page, set the signal when your data changes, and call the function `render` returns when the component is removed.

We'll draw how much fruit a shop sold today, in four steps.

## 1. Bars

A `Chart` sets the scale: here, from 0 to 30.
A `Plot` inside it gets the data.
Its child is the slat, written as a function of `d`, one row of the data.

**`Chart` and `Plot` are two different components.**
In everyday use a plot and a chart are the same thing, and these pages use both words that way: a bar chart, a box plot, a pie chart.
As components they have separate jobs.
A `Chart` is the frame, and it sets the scale, the direction, the axis and the theme.
A `Plot` is one stack of slats inside that frame, and every prop of it that is not a setting is a column of your data.
A Chart can hold more than one Plot, drawn over each other on the same scale.

<Demo name="first-bars" height={170} />

`sold` is a list, so the Plot makes one slat per number.
In each slat, `d.sold` is its row's number, and the `Bar` runs from 0 to it.

A slat is always one element that holds everything drawn in it: here, a `<div>` around the `Bar`.
rhp stacks that element with the others and moves it when the rows are sorted, and the blocks inside it are placed by their values.

## 2. Names and numbers

Give the Plot a second list, `fruit`, and each slat gets its item as `d.fruit`.
A `Label` with `edge="start"` sits at the start of the chart, and one with `at` sits just past a value.

<Demo name="first-labels" height={170} />

## 3. Data that changes

Keep the numbers in a signal, Solid's box for a value that changes.
When you set it, the chart updates: the bars grow or shrink.

`order` sorts the rows.
`sortBy("sold", "desc")` puts the largest first, and the slats slide to their new places.

<Demo name="first-live" height={210} />

Nothing else is needed: no update calls, no redraws.
The chart reads the signal, so it knows when the numbers change.

## 4. Style

`slat()` gives the slat its own look.
Its `css` is plain CSS for the classes in the slat, and it only reaches this chart's slats.
`thickness` sets each slat's height, and `series()` gives each slat a color from the theme.

<Demo name="first-styled" height={250} />

A few things to notice in the CSS:

- `.slat:hover` lights up the slat under the pointer.
- `--rhp-end-radius` rounds the bar's end only. rhp reads a few variables like this one; they're listed in [Styling](/guides/styling/).
- `var(--rhp-color)` is the bar's color, so the number matches its bar.
